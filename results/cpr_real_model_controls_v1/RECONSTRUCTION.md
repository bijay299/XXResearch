## Reconstructing the probe adapter

```python
import torch
from cprlib import flux_harness as FH, lora as LORA

H = FH.FluxHarness(device="cuda:0", dtype=torch.bfloat16)   # FLUX.1-dev @ 3de623fc
wrapped = H.attach_lora(seed=11)                            # qk_dual, r=16, a=16, p=0.1
blob = torch.load("entry_gate_bringup_probe_adapter.pt", map_location="cpu")
report = LORA.load_state_dict(wrapped, blob["state_dict"], strict=True)
assert LORA.state_hash(LORA.state_dict(wrapped)) == blob["state_hash"]
```

The snapshot stores only `lora_A`/`lora_B` for the 76 `qk_dual` modules
(FP32, 152 tensors) plus metadata — never a transformer copy. Verified at
bring-up: 152/152 keys, no missing/unexpected/nonfinite/shape mismatch,
identical state hash, and a fixed-input forward **bit-identical after reload**
(max abs diff 0.0). Run the comparison in **eval mode** — LoRA dropout p=0.1
makes a train-mode comparison stochastic. Unmerged/merged bit-equivalence is
**not** asserted.
