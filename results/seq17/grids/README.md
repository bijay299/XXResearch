# Blinded visual check

Rows are shuffled per category and labelled A/B/C...; the mapping is in `KEY_do_not_open_before_annotating.json`.

1. Open `blind_<category>.jpg`.
2. For each row and cell, record whether the named category is visibly present, in `annotation_sheet.csv`.
3. Only then open the key.

**No human annotation has been performed yet.** The sheet is empty by design. Any statement that images were human-reviewed must be backed by a filled-in copy of this sheet.
