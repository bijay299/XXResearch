## A note on links inside these files

These are **verbatim archived copies**. Their relative links still point at the
paths that were correct where they originally lived (`results/audit_v1/…`,
`results/…`), so from inside this directory many of them do not resolve. That is
deliberate: rewriting them would alter preserved text, and the point of the
archive is that it is unaltered. Follow the current documents for working links.
