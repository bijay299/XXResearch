## 1. Why this is the most direct comparison in the entire phase

IMMA's **§5.1 is this phase's experiment**, not an analogue of it:

| | IMMA §5.1 | this phase |
|---|---|---|
| base model | **SD v1-4** | **SD v1-4** |
| defended model | **ESD-erased** | ESD / UCE / AdvUnlearn / FRP / … |
| adversary | **LoRA re-learning** | LoRA (`FINDING53`) + 3 others |
| defence data | **20 images generated by SD before erasing** | 16 self-generated images |
| concepts | 8 art styles + 10 ImageNet objects incl. **parachute** | church, **parachute**, van_gogh, … |
| their framing | *"Immunizing erased models against re-learning"* | identical |

Same base model, same adversary family, overlapping concepts, same stated goal. Of the five
competitors this is the one whose published setting is closest to ours, so a disagreement cannot be
attributed to a domain change as readily as for FRP, Meta-Unlearning or GIFT.

It is also the **framework GIFT is built on** — GIFT §3.2 says so explicitly — and GIFT was reversed
on 22 of 22 valid attacks (`FINDING58`). So IMMA is both the ancestor of a method already tested here
and the closest published match to our own setting.

## 2. The algorithm, transcribed

Eq. (3), the bi-level program:

```
max_{θ∈S}  L_A(x'_I, c'; θ, φ*)      s.t.   φ* = argmin_φ L_A(x'_A, c'; θ, φ)
   upper                                              lower
```

Algorithm 1, verbatim structure:

```
θ_0 = θ_p ; initialise φ_0 per A
for i = 1..I:
    sample batches x'_A, x'_I independently from D
    φ ← φ_{i-1}                                        # WARM START, not reinitialised (line 5)
    φ_i ← argmin_φ L_A(x'_A, c'; θ_{i-1}, φ)           # approximated by ONE gradient step
    θ_{i-1 ∈ U} ← φ_i                                  # assign overlaps, variant (b) (line 7)
    θ_{i ∈ S} ← θ_{i-1 ∈ S} + α ∇_θ L_A(x'_I, c'; θ_{i-1}, φ_i)   # ASCENT (line 8)
```

**Three structural facts that distinguish IMMA from the two bi-level defences already tested here:**

1. **The inner loop runs the *real* adversary**, warm-started across outer iterations — not a
   simulated single step from scratch. Meta-Unlearning simulated one attacker step; GIFT alternated
   against a prior-preservation loss. IMMA actually trains LoRA inside its own training loop. This
   is the strongest of the three formulations.
2. **The upper level ASCENDS the adaptation loss** (`+α∇`), directly maximising how badly the
   adversary will do, rather than maximising a benign loss at a perturbed point.
3. **It is adversary-specific by construction.** `A` is a particular adaptation method, so an IMMA
   arm immunized against LoRA is not thereby immunized against anything else. That is a property of
   the method, not a limitation of the port, and it shapes the test design in §4.

Settings the paper **does** specify, unlike FRP's λ or GIFT's β:

- **S = cross-attention layers only** ("we choose S in Eq. (3) to contain only the cross-attention
  layer"). Same surface as our GIFT port's ψ — 80 `attn2` projections, 44.0M params, 5.11% of the
  UNet.
- **Adam** for the upper-level task (explicitly stated — so unlike our GIFT port, which used plain
  SGD because *that* paper's derivation required it).
- **One gradient step** for the lower-level task.
- **Overlap variant (b)**: assign `θ_{U} ← φ` before the upper-level gradient.

Unspecified and therefore pre-declared here: **α** (upper-level lr) = **1e-5**, inner lr = **1e-4**
(LoRA's usual scale), **I = 1500** outer iterations to match `H80`/`H81` budgets, LoRA rank **16**
to match our `FINDING53` adversary.

## 3. What IMMA is applied to

**Primary arm: `frp_church_r3_l05`** — the same base `H80` used, so Meta-Unlearning, GIFT-style
immunization and IMMA are all measured on top of an identical erased model and are directly
comparable. IMMA's own §5.1 immunizes an **ESD**-erased model; our ESD arm exists, so a **secondary
arm on ESD-church** is run to match their setting exactly, and is the one to believe if the two
disagree.

Note `U = ∅` when `A` is LoRA: LoRA introduces new parameters, so Algorithm 1 line 7 is a no-op in
the primary configuration. It becomes live only for DreamBooth, where φ ⊂ θ.

## 4. Protocol, and the one place this test must differ

`PROTOCOL_FROZEN_v1` six-point grid, `FINDING20` validity gate, `max-over-valid` H, `FINDING35` §4
ratchet — as for every other arm.

**But the primary measurement here is LoRA, not full-UNet relearning**, because LoRA is the
adversary IMMA is immunized against. Reporting only the full-UNet grid would test IMMA against an
adversary it never claimed to stop. So:

- **Primary:** LoRA rank-16, ≥ 2 seeds, on the IMMA-immunized arm vs the un-immunized arm. This is
  IMMA's own §5.1 comparison.
- **Secondary:** the full frozen six-point full-UNet grid, reported as a *transfer* question —
  does immunizing against LoRA buy anything against weight-space relearning?
- **Tertiary:** TI and DreamBooth, for the `FINDING54` matrix.

## 5. Kill rules

- **K1** retain8 < 0.60 as-is ⇒ reported as destroying the model, not attacked.
- **K2** low H with post-attack utility < 0.50 ⇒ self-destruction, not robustness.
- **K3** gate failures contribute nothing and are reported as attacks that did not work.
- **K4** any sub-ceiling H is provisional until LoRA *and* TI *and* full-UNet have been pushed.

## 6. Predictions, recorded before any arm is built

1. **Primary (LoRA):** IMMA will show a **real but partial** effect — max-over-valid H strictly below
   1.000 under LoRA, and strictly above the mandate's 0.40. Reasoning: unlike the other two, its
   inner loop trains the actual adversary, so the thing it optimises against is the thing we then
   run. I expect the first non-ceiling number in this phase. Falsified by H = 1.000 under LoRA.
2. **Secondary (transfer):** **no** transfer — full-UNet relearning reaches 1.000 regardless,
   because S is 5.11% of the UNet and an 859.5M-parameter adversary is not constrained by it. This
   is the same mechanism `FINDING58` §3a found for GIFT, where a 0.046% LoRA already sufficed.
3. **On the comparison that matters:** if (1) and (2) both hold, the phase's conclusion sharpens
   from *"every defence is reversed"* to *"defences can resist the adversary they were trained
   against and none resists a stronger one"* — which is a materially different and more useful
   statement than nine flat reversals.

**If prediction 1 fails and LoRA also reaches 1.000**, IMMA joins the other nine and the phase's
negative result is as flat as it currently looks. I will report that outcome without softening it.
