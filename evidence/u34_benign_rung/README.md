# U34 — the erased concept returns under **benign** fine-tuning, with no adversary

**2026-10-28.** Pre-registered in the U33 ladder prereg §5 as the BENIGN rung; implemented in
`scripts/benign_finetune.py`. **9 of 9 cells valid, n=3 per arm, no failures.**

## What was done

The erased model is fine-tuned for 200 steps on 32 images of **non-target** concepts — golf ball,
french horn, cassette player, english springer — generated by the base model. **No church prompt and
no church image appears anywhere in training.** We then ask whether the erased concept returned.

This is ResAlign's threat model (NeurIPS 2025, arXiv:2507.16302): ordinary downstream use, not an
attack. It is the first measurement in this project that is directly comparable to the one published
method that demonstrates resistance.

**Validity.** A benign fine-tune cannot be gated on target-prompt rise — the target was never trained
on. A cell counts only if the fine-tune actually trained: probe loss fell **and** weights moved past
the measured fp32 floor (7.6e-6). All nine cells pass, with `max|dW|` at 8.1e-4 to 8.7e-4, two orders
above the floor.

**Every arm recovers, in every seed.** ESD reaches full recovery. UCE goes from complete suppression
(0.0000) to 0.6000. IMMA — the method built to resist fine-tuning — goes from 0.0667 to 0.5333.

**Utility rises in every cell that had headroom** (0.8125 → 1.0000, 0.9375 → 1.0000, 0.7500 →
1.0000), and never falls. So this is **not damage**: the model becomes better at everything,
including the concept it was supposed to have forgotten. That is the project's recurring signature —
recovery while retained capability *rises* is only possible if nothing was removed.

## Why this is the strongest claim in the programme

Every other result here requires an adversary who wants the concept back. This one does not. It says
erasure degrades under **legitimate downstream use**: someone fine-tunes a released model for an
unrelated task and the erased concept quietly returns.

It also makes the three-tier attacker taxonomy an empirical result rather than a framing device. The
tiers do separate — ESD reaches 1.0000 benignly while UCE and IMMA reach only ~0.5 — but **no arm
holds.**

## Limits, stated rather than discovered

- **The downstream images are generated by the BASE model.** The fine-tuning target distribution is
  therefore base-model behaviour, which may pull the model toward base generally, including
  un-erasing. A real downstream dataset of photographs would not have this property so directly.
  **This is a genuine confound and the result must be repeated with real images before publication.**
- 200 steps, 32 images, one concept (church), SD-1.4, three arms, n=3.
- Not budget-matched to the capacity rungs (200 steps vs 25), by design: a downstream fine-tune is a
  training run, not a 25-step poke. The benign column is its own column and must not be interpolated
  into the capacity ladder.
- `H_after` is the same closed-set CLIP metric whose defects U29/U30 document. The target images for
  these nine cells have **not** been inspected.
